# Piste Noire

Appli perso de remise en forme : sobriété, sport, assiette. Objectif : ski en compétition en février.

- **Aujourd'hui** : série de jours sans alcool, 3 anneaux (Sobriété, Sport, Assiette), séance du jour à cocher, idée de dîner, pesée.
- **Calendrier** : défi sans alcool jusqu'à Noël, puis objectif hebdomadaire.
- **Sport** : programme en 4 phases (Reprise → Base → Force & explosivité → Affûtage), puis entretien.
- **Assiette** : règles anti-grignotage, 12 dîners à partager en famille, idées de déjeuners.
- **Bilan** : niveaux (piste verte → noire → hors-piste), badges, courbe de poids, réglages, sauvegarde.

Les données sont stockées dans le navigateur du téléphone (localStorage). Penser à exporter de temps en temps.

## Mise en ligne (GitHub Pages)
1. Créer le dépôt `piste-noire` et y déposer tous les fichiers.
2. Settings → Pages → Branch `main`, dossier `/root`.
3. Ouvrir `https://tomplzl.github.io/piste-noire/` sur l'iPhone → Partager → « Sur l'écran d'accueil ».
